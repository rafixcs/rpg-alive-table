# Projeto App de RPG de Mesa

O aplicativo tem como objetivo ter numa plataforma para auxiliar jogadores de RPG de mesa a ter suas notas centralizadas num lugar so. E utilizando agentes de IA para ajudar na criacao de historias, consulta das notas e etc.

## Notas
* Sistema de criador de ficha de personagem de RPG
* Anotacoes dos jogadore
    * HP
    * Mana
    * Status
    * Observacoes

* Chat de IA
    * Agente de IA que tem como objetivo ajudar o jogador a consultar as suas notas de forma mais simples se ter que ir nota por nota para procurar onde esta a informacao
    * Pode ajudar o player a tomar decisao sobre qual acao tomar

* Anotacoes do mestre
    * Mestre pode ter notas em pdf e/ou no caderno que se digitalizado o sistema deve extrair a informacao para as notas
    * Agente de IA pode ajudar o mestre a construir a historia
    * Ou pode construir sozinho

* Ferramenta de criacao de mapas
    * Primeira fase apenas criar os mapas, podendo fazer impressao para jogar com figures fisica
    * Utilizacao do mapa para jogar na propria plataforma

* Criar ambientes (workspace) para poder separar as historias dos jogadores
* Possibilidade de fazer video chamada para jogar com os amigos remotamente
